# kc-bt-temp

A custom WordPress block theme based on a starter block theme structure, adapted for building clean, flexible, modern page layouts in the Site Editor.

This theme is designed to be a simple foundation for creating custom block-based pages, reusable patterns, and custom styles.
This theme is based on Starter Block Theme v4 (https://jakson.co/), (C) Jakson, [GPLv2 or later](http://www.gnu.org/licenses/gpl-2.0.html).

## Features

- WordPress block theme structure
- Site Editor compatible
- Custom block patterns
- Custom block styles
- Responsive layout foundation
- Lightweight CSS framework utilities
- Font icon support
- Ready for customization and expansion

## Requirements

- WordPress 6.8 or newer
- PHP 7.4 or newer

## Installation

1. Upload the theme folder to:
   `wp-content/themes/kc-bt-temp`
2. Activate the theme in the WordPress admin
3. Open the Site Editor and start customizing templates, parts, and patterns

## Theme structure

Typical structure:

```text
kc-bt-temp/
├── assets/
│   ├── css/
│   ├── fonts/
│   └── js/
├── inc/
├── parts/
├── patterns/
├── templates/
├── functions.php
├── style.css
├── theme.json
└── readme.md
```

## Customization

This theme includes:
- template parts for header and footer
- block patterns for reusable layouts
- custom styles for core blocks
- support files for utility classes and icon fonts

You can extend it by:

- adding new patterns
- editing template parts
- creating new block styles
- updating theme.json
- adding custom CSS in style.css

## Notes

This theme is intended as a starting point for a custom block-based website.
It includes starter utilities and styles that can be adapted to your needs.
Keep theme-related layout and styling here, and put reusable blocks into a plugin if needed.
